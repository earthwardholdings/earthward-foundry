# Full Human Workforce Architecture

This is the complete long-range position catalog, organized by the same
eight houses the agent fleet mirrors. Earthward does not hire all of these
at once — see "The Foundational 25" below and `docs/build-order.md` for
sequencing. The agent fleet in `agents/` currently covers the Foundational
25 plus a handful of natural extensions (CAD specialist, alloy research,
configuration management, etc.) drawn from these lists.

## The Foundational 25

For a credible first operating facility, prioritize these 25:

1. Foundry General Manager
2. Chief / Principal Engineer
3. Manufacturing Engineer
4. Mechanical Design Engineer
5. Metallurgist
6. Materials Engineer
7. Foundry Process Engineer
8. CNC Machinist
9. Precision Machinist
10. Master Fabricator
11. Welder / Fabricator
12. Casting / Furnace Technician
13. Assembly Technician
14. Maintenance Technician
15. Automation / Controls Technician
16. Metrology Engineer
17. Quality Engineer
18. CMM / Precision Measurement Technician
19. NDT / Inspection Technician
20. Test & Validation Engineer
21. Technical Records / Traceability Specialist
22. Supply Chain / Procurement Manager
23. EHS / Safety Manager
24. Program / Project Manager
25. Technical Sales / Applications Engineer

Roles 8, 9, 11, 14, and 15 (CNC/Precision Machinist, Welder/Fabricator,
Maintenance Technician, Automation/Controls Technician) are hands-on floor
roles that the agent fleet supports (toolpath generation, WPS gap
flagging, predictive maintenance) rather than replaces — there is no
"CNC Machinist Agent" that operates a machine.
