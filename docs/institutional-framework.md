# Institutional Framework

Source: *Earthward Foundry & Works — Institutional Framework*
(Purpose · Works · Disciplines · Standards · Knowledge · Projects · People)

## Purpose

Earthward Foundry & Works exists to design, make, repair, inspect, and
maintain durable physical things. Work begins with a requirement or problem
and continues through design, materials, fabrication, inspection, testing,
documentation, maintenance, and repair.

**Operating principle:** Understand the work before making it. Use
appropriate materials. Build with care. Measure the result. Keep a useful
record. Maintain what is worth keeping.

## What Earthward does

- **Design** — turn requirements, constraints, and practical use into
  manufacturable designs.
- **Materials** — select, test, prepare, and understand materials used.
- **Fabrication** — cast, machine, weld, form, cut, finish components.
- **Assembly** — fit components together into working systems.
- **Inspection** — measure and determine whether results meet requirements.
- **Testing** — test performance, durability, reliability, suitability.
- **Repair & Maintenance** — restore, maintain, extend useful life.
- **Documentation** — maintain drawings, inspection records, material
  records, maintenance history, project documentation.

## The workflow

```
REQUIREMENT → DESIGN → MATERIAL → MAKE → ASSEMBLE → INSPECT → TEST → RELEASE → MAINTAIN
```

Not every project requires every stage; adapt to size, risk, and complexity.

## Standards of work

| Standard | Meaning |
|---|---|
| Clarity | The requirement should be understood before work begins. |
| Fitness | Material and method should fit the intended use. |
| Workmanship | Components made with appropriate care and repeatability. |
| Measurement | Important characteristics measured, not assumed. |
| Verification | Where performance matters, it is tested or demonstrated. |
| Traceability | Important decisions and results recorded to a useful degree. |
| Maintainability | Systems should be inspectable, repairable, maintainable. |
| Responsibility | Work accounts for safety, materials, energy, waste, long-term use. |

## Project record structure

```
THE NEED → REQUIREMENTS → CONSTRAINTS → DESIGN → MATERIALS → PROCESS →
INSPECTION → TESTING → RESULT → MAINTENANCE / NEXT STEPS
```

Supports internal documentation, customer handover, case studies, and
future maintenance without separate storytelling systems per project.

## Knowledge structure

- **Foundational** — durable reference: processes, terminology, material
  properties, inspection methods, safety practices.
- **Technical** — detailed methods, equipment notes, calculations,
  tolerances, procedures, testing practices.
- **Field** — what actually happened: projects, experiments, failures,
  repairs, improvements.
